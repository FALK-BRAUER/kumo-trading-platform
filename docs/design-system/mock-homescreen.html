Option B

Triage — one verdict, then only exceptions

Answers a single question: can I leave this alone? On a normal day it is almost empty by design and you close it in three seconds. P&L is present but deliberately not the headline, because the screen's job is to tell you when to act, not to entertain.

Option C

Phase-aware — the same screen, reordered by time of day

Option B's discipline plus the observation that the useful question changes. Before the open it is "will it trade correctly"; after the close it is "did it, and what did it cost". Same components, ranked differently. More to build and more to get wrong, so only worth it if the phases genuinely feel different to you in use.
